# 🚨 Mega Bank Hacking Practice Lab 🚨

**Welcome to Mega Bank — Your Ultimate Web Hacking Playground!**

---

## 🎯 About This Project

Mega Bank Hacking Practice Lab is a *cutting-edge*, **interactive web application** designed for security enthusiasts and learners to safely explore, exploit, and understand the most critical web vulnerabilities found in real-world applications.

Step into the shoes of an ethical hacker and take on a series of hands-on challenges modeled after the infamous **OWASP Top 10** vulnerabilities — all wrapped in a sleek, modern banking interface. Hone your skills, sharpen your mindset, and become a web security hero!

---

## 🚀 Features

### 🔐 Vulnerable Login Page
A deliberately flawed login system vulnerable to SQL injection and weak authentication — test your hacking arsenal against Mega Bank’s gates.

### 🛠️ OWASP Top 10 Focus
Explore, exploit, and learn these key attack vectors:
- **SQL Injection** — Extract data and bypass restrictions
- **Cross-Site Scripting (XSS)** — Inject and execute malicious scripts
- **File Upload Vulnerabilities** — Upload dangerous files and escalate attacks
- **Command Injection** — Run arbitrary commands remotely
- …and many more!

### 💡 Progressive Challenges
Unlock continuous, interconnected hacking challenges designed for *step-by-step mastery* of web security flaws.

### 📱 Responsive & Modern UI
Enjoy a clean, stylish interface expertly crafted for smooth use on desktop and mobile.
